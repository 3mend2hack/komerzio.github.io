# 🛒 CUBAZON

### Marketplace cubano para la compra y venta de productos, conectando vendedores independientes con compradores de toda la isla.

---

## 📌 Sobre el proyecto

**CUBAZON** es una plataforma de comercio electrónico diseñada específicamente para el mercado cubano. Su objetivo principal es facilitar la **compra y venta de productos** entre particulares y pequeños negocios, actuando como un puente digital que conecta **vendedores externos** (independientes, emprendedores, pequeños comercios) con **potenciales compradores** en toda Cuba.

A diferencia de los marketplaces tradicionales, CUBAZON está construido pensando en las necesidades y limitaciones del entorno cubano, ofreciendo una experiencia fluida, segura y accesible.

---

## 🎯 Objetivo principal

> **Crear un ecosistema digital donde los vendedores cubanos puedan ofrecer sus productos y los compradores encontrar lo que necesitan, todo en un solo lugar, con métodos de pago y comunicación adaptados a la realidad del país.**

### Funcionalidades clave:

- 🛍️ **Tienda online** con categorías de productos (electrónica, ropa, hogar, ofertas)
- 🤝 **Conexión con vendedores externos** — cualquier emprendedor puede ofrecer sus productos
- 💬 **Sistema de contacto integrado** (WhatsApp, Telegram, email) para que compradores y vendedores negocien directamente
- 🔐 **Autenticación segura** con Supabase (email, Google, Telegram)
- 🛡️ **Protección anti-bots** con Cloudflare Turnstile
- 📦 **Carrito de compras** y proceso de checkout
- 📍 **Geolocalización y envíos** adaptados a provincias cubanas
- 📱 **Diseño responsive** que funciona en cualquier dispositivo

## 🛠️ Tecnologías utilizadas

| Categoría | Tecnologías |
|-----------|-------------|
| **Frontend** | HTML5, CSS3, JavaScript (ES6+) |
| **Backend & Auth** | Supabase (PostgreSQL, Auth, Edge Functions) |
| **Seguridad** | Cloudflare Turnstile, MFA (2FA) |
| **Mapas** | Leaflet + OpenStreetMap |
| **Notificaciones** | EmailJS, Telegram Bot API |
| **Fuentes & Íconos** | Google Fonts, Font Awesome |
| **Alertas** | SweetAlert2 |

## 🚀 Características principales

### Para compradores:
- ✅ Navegar productos por categorías
- ✅ Buscar productos específicos
- ✅ Añadir al carrito y gestionar compras
- ✅ Contactar directamente con vendedores vía WhatsApp/Telegram
- ✅ Sistema de lista de deseos
- ✅ Métodos de pago adaptados (saldo CUBAZON, transferencias, etc.)

### Para vendedores externos:
- ✅ Espacio para ofrecer sus productos sin necesidad de tienda física
- ✅ Conexión directa con potenciales compradores
- ✅ Gestión básica de inventario (próximamente)
- ✅ Sistema de mensajería integrado

### Seguridad:
- 🔒 Autenticación de dos factores (2FA) obligatoria
- 🛡️ Protección contra bots en todos los formularios (Turnstile)
- 🔐 Sesiones seguras con Supabase
- 🚫 Sistema de bloqueo de usuarios (baneo)
